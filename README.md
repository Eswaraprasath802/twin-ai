# Kintra Recovery Digital Twin

A responsive Flask prototype for a post-operative recovery digital twin. It visualizes day-by-day recovery, flags early complication signals, and presents an adaptive rehabilitation plan.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`.
